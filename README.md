# GitBrief — case study + working prototype

- `index.html` — case study (opens at the site root)
- `auth.html` — start of the working prototype (linked from "Try the working prototype")

## Publish on GitHub Pages
1. Create a repo and upload everything in this folder to the root (keep `.nojekyll`).
2. Settings → Pages → Source: Deploy from branch → `main` / `(root)` → Save.
3. Your site: `https://<username>.github.io/<repo>/`

## Or Netlify
Drag this folder onto https://app.netlify.com/drop.
